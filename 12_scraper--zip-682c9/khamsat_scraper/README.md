# 🚀 برنامج استخراج بيانات خمسات الاحترافي

برنامج متقدم لاستخراج بيانات طلبات الخدمات من منصة خمسات باستخدام تقنيات Python الحديثة.

## ✨ المميزات

- **بنية احترافية**: فصل واضح بين الإعدادات (config)، النواة (core)، والأدوات (utils)
- **Pagination كامل**: تصفح تلقائي للصفحات مع حد أقصى قابل للتخصيص
- **استخراج التفاصيل الكاملة**: الدخول لكل صفحة طلب واستخراج جميع البيانات
- **تحليل ذكي للوقت العربي**: تحويل "منذ 3 أيام و5 ساعات" إلى datetime
- **معالجة أخطاء شاملة**: لا يوجد "قتل صامت" - جميع الأخطاء مسجلة
- **Retry Logic**: إعادة المحاولة التلقائية مع exponential backoff
- **تأخير عشوائي**: لتجنب الحظر واكتشاف البوتات
- **User-Agent Rotation**: تبديل User-Agent بشكل عشوائي
- **دعم كامل للعربية**: UTF-8 BOM، RTL، وطباعة ملونة
- **مخرجات متعددة**: CSV, JSON, وتقارير ملخصة
- **تسجيل متقدم**: نظام logging مع rotation

## ⚙️ التخصيص

### تعديل الإعدادات

افتح `config/settings.py` وعدّل القيم حسب احتياجاتك:

```python
# الحد الأقصى لعمر الطلب (أيام)
DAYS_LIMIT = 10

# الحد الأقصى للصفحات
MAX_PAGES = 50

# نطاق التأخير العشوائي (ثواني)
DELAY_RANGE = (1.5, 3.5)

# تفعيل/تعطيل استخراج التفاصيل الكاملة
INCLUDE_FULL_DETAILS = True

# تصدير CSV/JSON
EXPORT_CSV = True
EXPORT_JSON = True
```

### تعديل محددات CSS

إذا تغير هيكل موقع خمسات، عدّل `config/constants.py`:

```python
LIST_SELECTORS = {
    'request_item': [
        'div.thread--list-item',  # المحدد الأول
        'div.thread-item',         # fallback
        'li.request-item',         # fallback آخر
    ],
    # ... بقية المحددات
}
```

## 🔧 الوحدات الرئيسية

### 1. محرك الاستخراج (`core/scraper.py`)

- جلب الصفحات مع retry logic
- Pagination التلقائي
- التحقق من شرط التوقف الزمني
- استخراج التفاصيل الكاملة

### 2. محلل HTML (`core/parser.py`)

- استخدام BeautifulSoup
- محددات CSS متعددة مع fallback
- استخراج البيانات من القوائم والتفاصيل

### 3. محلل الوقت العربي (`utils/time_parser.py`)

يدعم الصيغ التالية:
- "منذ 3 أيام"
- "منذ 5 ساعات"
- "منذ 10 دقائق"
- "منذ أسبوعين"
- "منذ 3 أيام و5 ساعات"
- "الآن"، "حالياً"

### 4. نظام التسجيل (`utils/logger.py`)

- تسجيل في ملف وعلى الشاشة
- Rotation لتجنب الحجم الكبير
- مستويات متعددة (DEBUG, INFO, WARNING, ERROR, CRITICAL)

### 5. مصدر البيانات (`core/exporter.py`)

- CSV مع UTF-8 BOM لدعم العربية في Excel
- JSON منسق مع metadata
- تقرير ملخص بالإحصائيات

## ⚠️ ملاحظات مهمة

### احترام الموقع

- لا تكثر من الطلبات المتزامنة
- استخدم التأخير العشوائي
- احترم ملف robots.txt
- لا تستخدم البرنامج لأغراض ضارة

### احتمالية التغيير

- قد يتغير هيكل HTML لموقع خمسات
- راجع سجل الأخطاء (`logs/scraper_log_*.log`)
- عدّل محددات CSS عند الحاجة

### الأداء

- اضبط `MAX_CONCURRENT_REQUESTS` حسب قدرتك
- قلل `MAX_PAGES` إذا كان الاتصال بطيئاً
- عطل `INCLUDE_FULL_DETAILS` للسرعة

## 🐛 استكشاف الأخطاء

### المشكلة: لا يتم العثور على طلبات

**الحل**: 
1. راجع ملف السجل للأخطاء
2. تحقق من محددات CSS في `config/constants.py`
3. تأكد من أن الموقع ليس محظوراً

### المشكلة: حظر IP

**الحل**:
1. زد قيمة `DELAY_RANGE`
2. قلل `MAX_CONCURRENT_REQUESTS`
3. استخدم VPN أو بروكسي

### المشكلة: أخطاء في التحليل

**الحل**:
1. تأكد من تثبيت جميع المكتبات
2. راجع `requirements.txt`
3. شغّل بوضع `DEBUG_MODE = True`
